**On this page**, I will give an overview of my work log: I completed the internship program within 12 weeks, each week I studied theory, did labs and recorded what I did with other AWS services.

The work log was done over about 12 weeks, so I divided the content into 12 weeks as below so that I can know what I did in each week and what AWS knowledge and skills I learned.


**Week 1:** [ Understand basic AWS services, how to use the console & CLI.](1.1-week1/)

**Week 2:** [Explore core AWS services: IAM, EC2, IAM roles for EC2, Cloud9, S3 static website hosting, RDS, Lightsail, EC2 Auto Scaling, CloudWatch, Route 53 Hybrid DNS, AWS CLI, DynamoDB, and ElastiCache](1.2-week2/)

**Week 3:** [Explore networking and content delivery (CloudFront, Lambda@Edge), Windows Workloads and Managed Microsoft AD, migrate workloads with VM Import/Export and DMS, deploy Elastic Disaster Recovery, and optimize operations with Lambda automation, Grafana, and resource tagging](1.3-week3/)

**Week 4:** [Operate systems remotely with Systems Manager and Session Manager, deploy infrastructure as code with CloudFormation and AWS CDK, and optimize cost and resources with EC2 Right-Sizing, Service Quotas, and automated EBS snapshot lifecycle management](1.4-week4/)

**Week 5:** [Manage identity centrally with IAM Identity Center, restrict permissions with Permission Boundaries, monitor compliance with Security Hub, encrypt data with KMS, detect threats with GuardDuty, and apply S3 security best practices](1.5-week5/)

**Week 6:** [Build reliability into the infrastructure with AWS Backup, VPC Peering, and Transit Gateway; build event-driven architecture with SQS/SNS; deploy high availability for Windows/SQL Server; and start containerizing applications with Docker, ECS, and CI/CD](1.6-week6/)

**Week 7:** [Finish the Performance track (CI/CD for EKS, hybrid storage, advanced DynamoDB design, Step Functions), move into Cost Optimization (Savings Plans, cost visualization and analysis), and start modernizing a monolith application into microservices](1.7-week7/)

**Week 8:** [Finish the DevAx series with SPA authentication and AWS AI services (Polly, Rekognition, Lex), build the entire Serverless Book Store application (Lambda, SAM, Cognito, SSL, SQS/SNS, CI/CD, monitoring, AppSync), and start a Document Management System with Amplify](1.8-week8/)

**Week 9:** [Finish the Document Management System series, complete two serverless workshops (a theme park application and a chat application), deploy applications with Elastic Beanstalk, and start Container services with Kubernetes/EKS and Docker/ECS/Fargate](1.9-week9/)

**Week 10:** [Finish the Container category (EKS Blueprints, CI/CD for EKS, ROSA) and start building a data lake on AWS](1.10-week10/)

**Week 11:** [Build a data lake with self-prepared data using Glue DataBrew, get an overview of AWS data analytics services, build dashboards with Amazon QuickSight, and practice the Data Engineering Immersion Day](1.11-week11/)

**Week 12:** [Practice advanced Amazon Athena, work with Amazon RDS PostgreSQL (upgrades, backup/recovery, high availability, application connectivity), and get familiar with Machine Learning using Amazon SageMaker](1.12-week12/)
